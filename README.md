
# Little Farm Adventure 🌾

This is a simple 2D farming game I made using Python and Pygame.

I made this project to practice Python and learn more about game development.

## Features
- Move around the farm
- Grow and collect crops
- Collect milk and eggs
- Buy and sell items
- Open and close gates
- Store items in a chest

## Controls
- **W A S D** - Move
- **E** - Collect items
- **G** - Open/Close gates
- **R** - Plant seeds
- **F** - Shop
- **I** - Inventory
- **ESC** - Exit

## How to Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```

Make sure the Assets folder is in the same folder as main.py.
